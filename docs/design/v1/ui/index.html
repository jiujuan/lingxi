1. 退款适用范围

客户在订阅服务开通后 7 天内，且用量未超过套餐配额 10% 时，可申请原路退款。企业客户合同条款优先级高于通用退款规则。

客服需确认订单号、付款流水、企业主体和开票状态。已开具发票的订单必须先完成红冲流程。
