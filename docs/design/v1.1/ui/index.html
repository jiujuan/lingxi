核心闭环流程

管理员导入知识后，员工按权限提问并查看引用。

1上传文档PDF、Word、扫描件，设置部门和角色权限。
2解析与 QA解析章节、表格、页码，拆分为问题-答案对。
3建立索引qa_question 写入 pgvector，全文字段写入 tsvector。
4混合检索SQL 前置权限过滤，BM25 + 向量召回。
5引用回答SSE 流式输出，引用可点击查看原文。

可问答

1. 退款适用范围

客户在订阅服务开通后 7 天内，且用量未超过套餐配额 10% 时，可申请原路退款。企业客户合同条款优先级高于通用退款规则。

2. 开票订单处理

已开具发票的订单必须先完成红冲流程，客服需确认订单号、付款流水、企业主体和发票状态。该规则属于高风险承诺场景。
