# 后台管理列表样式统一设计

## 目标

将以下后台列表调整为“日志排障”页面的紧凑表格视觉，同时保持现有列、数据请求、权限控制与操作行为不变：

- API Key 页的调用日志
- 模型配置页的供应商列表和模型实例列表
- 部门管理页的部门列表
- 用户管理页的用户列表

API Key 页的 Key 列表不在本次范围内。

## 表格规范

- 列表面板使用白色背景、细边框和 8px 圆角。
- 标题区、表头和数据行沿用日志列表的文字颜色与层级。
- 表头最小高度为 44px，数据行最小高度为 62px。
- 主列显示主文本和原有的副文本；其余字段保持原顺序与原值。
- 状态以现有状态标签展示，尺寸收紧为 12px 字号和 3px 纵向内边距。
- 数据行之间使用浅色分隔线。
- 移动端隐藏表头；每行转为主信息加右侧操作，其他字段纵向展开。

## 操作样式

- 原有操作按钮保留其触发逻辑和禁用状态，但渲染为无边框、透明背景的文字按钮。
- 默认操作文字为蓝色；悬停时显示浅蓝色背景和蓝色文字。
- 删除操作为红色文字；悬停时显示浅红色背景。
- 编辑与删除操作使用现有图标库中的编辑、删除图标；其余文字操作保持原名称。
- 操作按钮采用 5px 圆角、14px 字号和紧凑内边距，不显示黑色或灰色外框。

## 页面映射

### API Key 调用日志

- 显示请求路径、Key 前缀、HTTP 状态、耗时、请求 ID。
- 保留当前数据加载方式；接口不返回分页元数据，因此不新增分页。

### 模型配置

- 供应商列表保留名称、类型、Secret 配置、状态以及测试连接、编辑、删除操作。
- 模型实例保留模型名、能力、默认标识、状态以及设为默认、编辑、删除操作。
- 两个接口均不返回分页元数据，因此不新增分页。

### 部门管理

- 保留部门树的顺序、层级缩进、编码、人数和创建时间。
- 编辑、删除操作仅在现有写权限可用时显示。
- 接口不返回分页元数据，因此不新增分页。

### 用户管理

- 保留姓名/邮箱、部门、角色、状态、创建时间和全部原有操作。
- 现有分页逻辑不变，仅替换为日志列表同款分页样式和页码展示。

## 验收

- 桌面端五处列表具有一致的标题、表头、62px 行高、状态标签和操作链接样式。
- 鼠标悬停常规操作显示浅蓝背景，删除显示浅红背景，不出现外框。
- 用户分页与日志页分页的视觉一致。
- 窄屏下不出现水平溢出，列表按移动端规则重排。
- TypeScript 检查、生产构建和相关 Playwright 验收通过。
